# Meta-Sovereignty Decision Model
**——一个以第一性原理构建的人类动机元理论**

> **核心边界**：逻辑管"是不是"，主权裁决管"做不做"。两个问题，两套系统，不互相取代。

## 📖 项目简介
本项目将荣格的内倾情感（Fi）重构为心理系统中唯一的 **“主权价值裁决功能”** 。通过第一性原理推演，提出了**伪Fi的三形态渗透模型**、**表征主权与执行主权二分解**，以及**非线性主权复健动力学**。这是一个用于解构原生家庭控制、精神内耗及代际创伤的底层系统架构。
