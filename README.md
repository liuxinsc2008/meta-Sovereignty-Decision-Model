# Human-Dynamics-4D: 主权价值裁决元心理学模型

> **“逻辑管‘是不是’，主权裁决管‘做不做’。两个问题，两套系统，不互相取代。”**

## 🧠 项目简介
本项目是一个基于第一性原理建构的元心理学理论。我们将荣格（Carl Jung）的内倾情感（Fi）重构为心理系统中唯一的**“主权价值裁决功能”**，其余七种功能皆为其执行工具。本模型致力于用系统动力学的视角，解构人类动机、原生家庭控制（NPD恶龙）、精神病理学（抑郁/自毁）以及主权复健的底层代码。

## ⚙️ 核心公理
1. **功能二元论**：心灵由唯一且不可替代的“主权裁决功能”与多元的“认知执行功能”构成。
2. **情感-价值启动原则**：任何主动行为，必须先经过主权裁决功能赋予正向情感-价值标记。
3. **价值体系的主动建构法则**：价值体系必须经由“内化裁决”才能更新，解释了为什么“懂了道理却过不好一生”。

## 🧭 四维相空间雷达 (X, Y, Z, W)
本模型拒绝静态的人格标签，采用四维连续变量对个体状态进行精准定位：
*   **X轴（回避度）**：行为矢量，趋近或撤退。
*   **Y轴（焦虑度）**：能量标量，警报或平静。
*   **Z轴（需求压抑值）**：内核深度，真实表达与假性疏离。
*   **W轴（安全混乱波动值）**：系统稳定性，稳态与高频震荡崩溃。
